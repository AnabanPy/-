## Описание

Десктоп-приложение для автоматизации приема, регистрации и классификации промышленных отходов.  
Позволяет регистрировать партии отходов, автоматически подбирать код ФККО, присваивать класс опасности, формировать приемо-сдаточные документы и вести историю поступлений.

---

## Требования

- Windows 10 / 11
- Python 3.11 или выше
- Подключение к интернету (для работы с сервером)

---

## Установка и запуск

### 1. Установите необходимые библиотеки

```bash
pip install -r requirements.txt
```
### 2. Запустите программу

```bash
python main.py
```
